TCF Practice Center · System Overview

A preparation platform for the TCF Canada speaking exam. One Docker image on Render serves the React bundle and the API from a single origin; Postgres on Neon holds a four-layer question model. Scraping, labelling and review all run from the admin system inside the browser.

Agreement as triagetwo models on the same questions; the answers they share are accepted in one action, and only the split ones reach a person. 85–86% single-model against a hand-built gold set, 90–92% agreement-filtered.
Identity a question is its normalised SHA-256 fingerprint — (tache, fingerprint), since the same wording under Task 2 and Task 3 is two questions. Frequency counted in distinct exam months, not scraped reports: 18% of month-entries were filed by more than one source.
